# Audit resolution: edition 1.1 (draft)

This edition was reworked on the basis of the audit **"Аудит GitHub-проекта Two Worlds. One Mind."**
(*Audit of the GitHub project Two Worlds. One Mind.*), written by **Codex** on **5 October 2026**, which
examined `main` at commit `7c05fe254acb22f3547528524ed97e92be81854d` (release `v1.0`). The audit
report itself is not published here. The audit's snapshot was checked against the live repository
before work began: `main` was still at that commit, `v1.0` was the only release, no workflow existed.

**Scope of the closure, honestly:** of the 25 findings, **16 are resolved**, **6 are partially resolved**,
**1 needs author data** and **2 need account access**. "Resolved" means: fixed in the files of this branch
and verified by an executed check or by inspection, as written in the *Verification* column; it does not
mean that anything has been published. Nothing in this edition has been merged or released; the edition
is a draft. On 5 October 2026 the author answered all questions in [author-questions.md](author-questions.md);
the answers are applied in the files and change the rows G01, C06, C07, R03 and R04 below.

Status vocabulary: `resolved`, `partially resolved`, `needs author data`, `needs account access`,
`not applicable`. The self-test (`scripts/selftest.py`) injects 18 defects, among them the audit's own (invalid CFF type, essay DOI in the book record, promise of storage, wrong chapter in a link caption, a returning absolute, an invented EXP-001 number) and shows that each is caught. Checks named below are in `scripts/` (see [build.md](build.md)); results are in the
[verification report](verification-report.md).
