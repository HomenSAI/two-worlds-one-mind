(decided by the author on 5 October 2026); the legal text is in [LICENSE-CODE](LICENSE-CODE). The

CC BY 4.0 as listed above.

## How GitHub recognises the licence

`LICENSE` now contains the unmodified standard CC BY 4.0 legal text, which GitHub's licence
detection is built to recognise. The result is checked in the repository's page after the change
reaches the default branch; see [docs/github-settings.md](docs/github-settings.md).
